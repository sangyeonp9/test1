# 📸 사진 → 블로그 글 (GitHub + 웹 Claude Code)

GitHub에 사진을 올리고 웹 Claude Code에 한마디만 하면 블로그 글을 써 줍니다.
설치할 것도, 추가 비용도 없습니다.

```
photo-blog/
├── photos/     ← 여기에 사진을 올리세요 (하위 폴더로 정리해도 OK)
├── blog/       ← 완성된 블로그 글(.md)이 저장됩니다
└── prompt.md   ← 글 스타일 가이드 (말투·형식 수정)
```

---

## 1. 사진 올리기 (GitHub 웹사이트)

1. 브라우저에서 저장소를 열고 `photo-blog` → `photos` 폴더로 들어갑니다.
2. 오른쪽 위 **Add file → Upload files**를 누릅니다.
3. 사진을 끌어다 놓거나 **choose your files**로 선택합니다. 여러 장을 한 번에 올려도 됩니다.
4. 아래 **Commit changes** 버튼을 누릅니다.

> 휴대폰 브라우저에서도 같은 방법으로 올릴 수 있습니다. 사진 한 장은 25MB 이하여야 합니다.

### 폴더로 정리하고 싶다면
Upload files 화면에서는 폴더를 만들 수 없습니다. 대신 **Add file → Create new file**을 누르고 이름 칸에 `제주여행/` 처럼 슬래시까지 입력하면 폴더가 생깁니다. 그 안에서 다시 Upload files를 하면 됩니다.
폴더 이름도 글을 쓸 때 참고합니다.

---

## 2. 글 써 달라고 하기 (웹 Claude Code)

1. **claude.ai/code**에서 이 저장소(`test1`)로 새 세션을 엽니다.
2. 이렇게 입력합니다.

   ```
   새 사진 블로그 글 써줘
   ```

   또는 `/photo-blog`라고 입력해도 됩니다.

3. Claude가 아직 글이 없는 사진을 모두 찾아 글을 쓰고,
   - 채팅창에 **완성된 글을 보여 줍니다** → 바로 복사해서 블로그에 붙여 넣으면 됩니다.
   - `blog` 폴더에도 저장하고 PR을 만듭니다.

특정 사진만 원하면 `photos/제주여행/성산일출봉.jpg 글 써줘`처럼 말하면 됩니다.

---

## 3. 저장된 글을 GitHub에 반영하기

Claude가 만든 PR 링크를 열고 **Ready for review → Merge pull request → Confirm merge**를 누르면 `blog` 폴더에 글이 저장됩니다.

> 반영하지 않으면 다음에 "새 사진 글 써줘"라고 할 때 같은 사진의 글을 다시 씁니다.
> 블로그에 글을 복사해 붙여 넣는 것만 필요하다면 반영하지 않아도 됩니다.

## 글 스타일 바꾸기

`prompt.md`를 GitHub에서 열고 연필 아이콘(✏️)을 눌러 수정한 뒤 **Commit changes**를 누르세요.
예: 반말로, 더 길게, 맛집 리뷰 형식으로 등.
