# 📸 사진 → 블로그 글 자동 작성기 (Mac)

`photos` 폴더에 사진을 넣으면 **Claude Code**가 사진을 보고 블로그 글을 써서 `blog` 폴더에 저장합니다.
API 키 없이 **지금 쓰는 Claude 구독 계정**으로 동작합니다. 구독 플랜의 사용량 한도 안에서 동작합니다.

```
photo-blog-writer/
├── photos/          ← 여기에 사진을 넣으세요 (하위 폴더로 정리해도 OK)
├── blog/            ← 완성된 블로그 글(.md)이 저장됩니다
├── prompt.md        ← 글 스타일 지시문 (말투·형식 수정)
├── photo_blog.py    ← 프로그램 본체
└── start.command    ← 더블클릭으로 실행
```

---

## 1. 처음 한 번만: 준비하기

Mac에서 **터미널** 앱을 엽니다. Spotlight(⌘ + Space)에서 "터미널"을 검색하면 됩니다.

### ① Claude Code 설치

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### ② Claude Code 로그인

```bash
claude
```

화면 안내에 따라 Claude 계정으로 로그인한 뒤 `/exit`를 입력해 나옵니다.

### ③ Python 확인

```bash
python3 --version
```

버전이 표시되면 준비가 끝난 것입니다. "개발자 도구 설치" 창이 뜨면 **설치**를 누르고 기다린 뒤 다시 확인합니다.

### ④ 이 폴더를 Mac으로 가져오기

GitHub 저장소 페이지에서 **Code → Download ZIP**을 눌러 내려받고 압축을 풉니다.
그 안의 `photo-blog-writer` 폴더를 원하는 위치(예: `문서`)로 옮깁니다.

---

## 2. 실행하기

### 방법 A: 더블클릭 (간편)

`start.command` 파일을 더블클릭합니다.

> 처음에 "확인되지 않은 개발자" 경고가 나오면 파일을 **우클릭 → 열기 → 열기**를 누르세요. 한 번만 하면 됩니다.

### 방법 B: 터미널

```bash
cd ~/Documents/photo-blog-writer
```

```bash
python3 photo_blog.py
```

### 실행되면

```
[14:02:11] 📂 감시 시작: .../photo-blog-writer/photos
[14:02:11]    사진을 넣으면 자동으로 글을 씁니다. 종료하려면 Control + C
```

이제 `photos` 폴더에 사진을 넣으면 30초~1분 뒤 `blog` 폴더에 글이 생기고, Mac 알림으로도 알려 줍니다.
**터미널 창을 닫으면 감시가 멈추니** 작업하는 동안 창을 열어 두세요.

---

## 3. 알아 두면 좋은 점

| 상황 | 동작 |
|---|---|
| 처음 실행할 때 이미 폴더에 있던 사진 | 건너뜁니다. 처리하려면 `python3 photo_blog.py --include-existing` |
| 사진을 하위 폴더로 옮기거나 이름을 바꿈 | 같은 사진으로 인식해서 **다시 쓰지 않습니다** |
| 아이폰 사진(HEIC) | 자동으로 JPG로 변환해서 처리합니다 |
| 폴더 이름 (예: `photos/2026-11 제주여행/`) | 글을 쓸 때 참고 정보로 활용합니다 |
| 글 작성 실패 | 해당 사진만 건너뜁니다. 프로그램을 다시 실행하면 재시도합니다 |
| 한 번만 처리하고 끝내기 | `python3 photo_blog.py --once` |
| 처음부터 다시 처리하고 싶을 때 | `.processed.json` 파일을 삭제하세요 (숨김 파일: Finder에서 ⌘ + Shift + . 로 표시) |

### 글 스타일 바꾸기

`prompt.md` 파일을 텍스트 편집기로 열어 수정하면 다음 사진부터 반영됩니다.
예: 말투를 반말로, 분량을 더 길게, 맛집 리뷰 형식으로 등.

### 블로그 글 보기

`.md` 파일은 텍스트 편집기로 열 수 있습니다. Typora, Obsidian 같은 마크다운 앱을 쓰면 사진과 함께 보기 좋게 표시됩니다.
