# 한숲GO

용인시 처인구 남사읍 **한숲시티 1~6단지와 남곡초등학교 일대**를 배경으로 하는 위치 기반 몬스터 수집 게임입니다.
갤럭시 등 스마트폰의 크롬 브라우저에서 바로 실행되며, 앱을 설치하지 않아도 됩니다.

## 게임 방법

### 도감 (36종)

| 종류 | 수 | 잡는 방법 |
|---|---|---|
| 몬스터 | 16 | **숲볼 던지기**: 숲볼을 위로 밀어 던져요. 링이 작을 때 맞히면 잘 잡혀요. |
| 곤충 | 8 | **잠자리채**: 날아다니는 곤충을 톡 눌러 채집해요. 한 마리에 5번까지 휘두를 수 있어요. |
| 동물 | 8 | **간식 주기**: 움직이는 막대가 초록 칸에 있을 때 간식을 주세요. 하트 3개면 친구가 돼요. |
| 물고기 | 4 | **낚시**: 버튼을 꾹 누르면 초록 칸이 올라가요. 물고기를 칸 안에 붙잡아 두면 낚여요. |

### 어디서 무엇이 나올까

| 장소·시간 | 잘 나오는 것 |
|---|---|
| 🎣 한숲물빛공원 연못 | 물고기 4종, 꽥꽥이(오리), 개굴돌이(개구리) — **연못에서만** 나와요 |
| 🦋 산내음공원·햇빛공원 | 무당별이, 노랑나풀이, 장수뿔돌이 같은 곤충과 깡총토끼, 도토리람 |
| ★ 남곡초등학교 주변 | 책벌레뭉, 종소리냥. 특별 거점에서는 아주 드물게 전설의 **한숲왕** |
| 🌙 밤 (19~6시) | 반짝반디, 달빛토끼, 별똥이, 장수뿔돌이, 집게왕, 고슴뭉 |
| ☀ 낮 (6~19시) | 구름솜, 노랑나풀이, 꿀벌이, 맴맴이, 산책멍멍이, 짹짹참새 |

### 그 밖의 기능

| 기능 | 설명 |
|---|---|
| 지도 | 실제 동네 지도(OpenStreetMap) 위에 내 위치가 GPS로 표시됩니다. |
| 출현 | 15분마다 주변에 새로 나타납니다. 같은 시간, 같은 장소에는 친구 모두에게 같은 것이 나타납니다. |
| 거점 | 한숲시티 단지 거점에서 숲볼 5개와 간식 3개를 받습니다 (5분마다). |
| ★ 남곡초등학교 | 특별 거점: 숲볼 10개, 간식 5개, 하루 한 번 특별한 몬스터. |
| AR | 잡기 화면에서 `AR 켜기`를 누르면 카메라 화면 위에 나타납니다 (낚시 제외). |
| 친구 도감 | 같은 친구 코드를 쓰는 사람끼리 순위, 서로의 도감, 최근 소식을 함께 봅니다. |
| 산책 연습 모드 | 집에서 지도를 눌러 이동하며 연습할 수 있습니다. |

## 1. 휴대폰에서 열기 (GitHub Pages)

이 저장소는 기본 브랜치(`claude/financial-chart-website-3wk87`)에 병합되면 GitHub Pages로 자동 배포됩니다.
따로 설정을 바꿀 필요는 없습니다.

1. 변경 사항을 기본 브랜치에 병합합니다.
2. 저장소의 **Actions** 탭에서 `pages build and deployment`가 끝나기를 기다립니다 (1분 내외).
3. 배포가 끝나면 휴대폰 크롬에서 엽니다:
   `https://sangyeonp9.github.io/test1/hansup-go/`
4. 크롬 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

> GPS와 카메라는 보안 때문에 `https://` 주소에서만 동작합니다. GitHub Pages는 https이므로 문제없습니다.

## 2. 친구 도감 공유 켜기 (Firebase, 무료)

설정하지 않으면 혼자 하기 모드로 동작합니다(기록은 각자 휴대폰에만 저장).

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름 예: `hansup-go`, 애널리틱스는 꺼도 됨).
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정.
3. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, 프로덕션 모드).
4. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여 넣고 **게시**.
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱(</>) 추가** 후 표시되는 `firebaseConfig` 값 중
   `apiKey`, `authDomain`, `projectId`, `appId`를 `js/config.js`의 `firebase` 항목에 넣습니다.
6. **Authentication → 설정 → 승인된 도메인**에 `sangyeonp9.github.io`를 추가합니다.
7. 커밋해서 다시 배포하면, 친구 모두 **같은 친구 코드**(예: `HANSUP-1004`)를 입력해 함께 플레이할 수 있습니다.

Firebase의 `apiKey`는 비밀번호가 아니라 앱을 구분하는 값이라 공개 저장소에 있어도 괜찮습니다. 데이터는 `firestore.rules`로 보호됩니다.
공유되는 정보는 **닉네임, 레벨, 도감 기록**뿐이며 **위치는 공유하지 않습니다.**

## 3. 거점 위치 고치기

`js/config.js`의 거점 좌표는 네이버 지도의 한숲시티 화면에 맞춰 두었습니다 (남곡초, 2·3·5·6단지). **1단지와 4단지는 주소로 추정한 값**입니다.
정확한 위치로 고치려면:

1. 게임 지도에서 원하는 지점을 **길게 누르면** 좌표가 나옵니다 (또는 네이버/카카오 지도에서 확인).
2. `js/config.js`의 `stops` 항목에서 해당 거점의 `lat`(위도), `lng`(경도)를 바꿉니다.
3. 새 거점을 추가하려면 같은 형식으로 한 줄을 더 넣으면 됩니다.

출현 빈도, 잡기 거리, 숲볼 개수 등도 같은 파일에서 바꿀 수 있습니다.

## 파일 구성

```
hansup-go/
├── index.html          화면 구성
├── css/game.css        디자인
├── js/config.js        거점·규칙·Firebase 설정
├── js/monsters.js      도감 36종(몬스터·곤충·동물·물고기) 데이터와 그림
├── js/spawn.js         출현 계산 (시간+위치+연못/공원 구역)
├── js/catch.js         잡기 화면 (숲볼·잠자리채·간식·낚시, AR 카메라)
├── js/store.js         기록 저장, 친구 공유
├── js/app.js           지도, 도감, 친구, 설정 화면
├── firestore.rules     친구 공유 보안 규칙
└── manifest.webmanifest, icon.svg   홈 화면 추가용
```

모든 캐릭터는 이 게임을 위해 새로 만든 오리지널 캐릭터입니다.
